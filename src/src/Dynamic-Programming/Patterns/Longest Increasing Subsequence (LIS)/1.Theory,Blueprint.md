# Longest Increasing Subsequence

## Blueprint

### Recursion + Memoization
```java
public int solve(int[] nums, int idx, int lastIdx, int[][] dp) {
        if (idx >= nums.length) return 0;

        if (dp[idx+1][lastIdx+1] != -1) return dp[idx+1][lastIdx+1];

        int skip=solve(nums, idx + 1, lastIdx,dp);

        int take=0;

        if (lastIdx==-1 ||nums[idx] > nums[lastIdx] ) {
            take = 1 + solve(nums, idx + 1, idx,dp);
        } 

        return dp[idx+1][lastIdx+1]=Math.max(take,skip);
    }

```

### Tabulation / Bottom Up
```java
 public int solveTab(int[] nums){
        int[][] dp=new int[nums.length+1][nums.length+1];

        for(int i=nums.length-1;i>=0;i--){// this represent the index 
            for(int j=i-1;j>=-1;j--){//j represent prevIndex and i cannot be bigger then the current index i.e. i so , j starts from i-1 -> -1. -1 representing the prevIdx of 0 or base case.
                int skip=dp[i+1][j+1];

                int take=0;
                if(j==-1 || nums[i]>nums[j]){
                    take=1+dp[i+1][i+1];

                }

                dp[i][j+1]=Math.max(skip,take);
            }
        }

        return dp[0][0];
    }
```
### Binary Search : We only want the count not the proper arrangement so we can use Binary Search
```java
public int binarySearch(int[] nums){
        int[] tails=new int[nums.length];
        int size=0;
                                                        
        for(int num:nums){
            int low=0;
            int high=size;

            while(low<high){
                int mid=low+(high-low)/2;

                if(tails[mid]<num){
                    low=mid+1;
                }else{
                    high=mid;
                }

            }

            tails[low]=num;

            if(low==size){
                size++;
            }
            
            
        }


        return size;
    }

```
